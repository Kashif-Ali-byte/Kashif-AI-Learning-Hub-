Welcome to my personal AI Learning Portfolio & Platform. This repository documents my 10+ month journey into Artificial Intelligence, covering everything from foundational computer science to advanced AI automation and engineering.

## 📚 About This Project

This is a structured, interactive learning hub built with pure HTML, CSS, and JavaScript. It organizes my AI training into clear tracks, modules, and lectures, making it easy to revisit concepts and track progress.

### 🎯 Purpose
- Showcase my AI learning roadmap.
- Serve as a central repository for all my lecture notes, code snippets, and project ideas.
- Demonstrate my ability to build a fully functional, mobile-friendly web platform.
